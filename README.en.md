This modified version retains original copyright and links. Original author may request removal of this post.

Key modifications:
1. Added all 11.0 dungeon bosses and trash strategies (focus on interrupt priorities and lethal skills)
2. Default collapsed strategy window (to avoid UI clutter)
3. Right-click to show/hide window, shout strategy via right-click
4. Auto-channel detection: Raid > Party > Say based on group size
5. Added {rt8} skull markers for boss names, {rt1} star icons for critical skills
6. Clean formatting: Remove icons and convert || to line breaks when displayed
7. Fixed strategy sending order
8. Added movable UI elements with position saving
9. Resizable strategy window
